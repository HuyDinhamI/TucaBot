🚀 Cách sử dụng:

  1. Khởi động backend API: python src/api.py
  2. Mở file index.html trong trình duyệt
  3. Hoặc chạy: cd frontend && python -m http.server 8000
  4. Truy cập: http://localhost:8000

🔧 Cấu hình API

Mặc định API URL: http://localhost:9998/mavap/api

Để thay đổi, sửa trong file js/app.js:

const CONFIG = {
    API_BASE_URL:  'http://localhost:9998/mavap/api',
    // ...
};

🎯 Event Handling

Frontend xử lý các events từ LangGraph:

  • on_think_event: Hiển thị trong Thinking Box
  • on_answer_event: Hiển thị câu trả lời chính
  • on_blocked_event: Cảnh báo nội dung bị chặn
  • on_chat_model_stream: Stream text từ LLM
  • Node-specific events: ask_user, gather_user_information_agent, general_agent, answer_agent
